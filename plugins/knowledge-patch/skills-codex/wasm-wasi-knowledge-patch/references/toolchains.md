# Initial WASI async toolchain

## Minimum tool versions

The initial wasi-0.3-guide toolchain requires:

| Tool | Requirement |
| --- | --- |
| Wasmtime | 46 or newer |
| `wit-bindgen` | 0.46 or newer, with the `async` feature |
| `wkg` | 0.15 or newer for 0.3 packages |

Wasmtime 46 enables WASI 0.3 and `component-model-async` by default.

## JavaScript hosts

Use jco's `preview3-shim` for JavaScript host bindings
(wasi-0.3-guide).

## Rust compiler channel

Initial Rust builds require nightly (wasi-0.3-guide). Stable Rust bundles a
`wasm-component-ld` that is too old for the 0.3 component output generated by
`wit-bindgen` 0.58.

If component linking fails despite using the minimum binding-generator
version, check all three relevant versions rather than changing WIT first:

- the Rust compiler channel;
- the bundled `wasm-component-ld`; and
- the `wit-bindgen` version producing the component.
