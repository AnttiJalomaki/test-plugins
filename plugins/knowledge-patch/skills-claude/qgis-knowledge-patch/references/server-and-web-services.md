# Server and web services

## Project loading and capabilities

### Configure the project cache

Since 3.44, `QGIS_SERVER_PROJECT_CACHE_SIZE` sets the QCache cost used for the
QGIS Server project cache instead of relying on the former hardcoded value.

### Publish layer-tree group metadata

Since 3.44, layer-tree groups can publish keywords, a data URL and format,
attribution title and URL, metadata URLs, and a legend URL and format through
GetCapabilities. These augment short name, title, and abstract. When no legend
URL is set, a legend is generated by default.

### Retry temporarily invalid layers

Since 4.0, `QGIS_SERVER_RETRY_BAD_LAYERS=true` makes the server retest layers
previously accepted as bad on every request. A layer returns to service when
its dependency recovers.

## GetFeatureInfo and WMS

### Return only maptips in HTML GetFeatureInfo

Since 4.0, a project-level setting can make HTML GetFeatureInfo use only the
layer maptip. It corresponds to the WMS vendor parameter
`WITH_MAPTIP=HTML_FI_ONLY_MAPTIP`.

### Query mesh layers

Since 4.0, QGIS Server can answer GetFeatureInfo requests for mesh layers.

### Style highlight-label frames

Since 4.2, WMS requests can style highlight-label frames using:

- `HIGHLIGHT_LABELFRAMEBACKGROUNDCOLOR`
- `HIGHLIGHT_LABELFRAMEOUTLINECOLOR`
- `HIGHLIGHT_LABELFRAMEOUTLINEWIDTH`
- `HIGHLIGHT_LABELFRAMESIZE`

Parameters may be map-scoped, for example
`MAP0:HIGHLIGHT_LABELFRAMESIZE=5`.

## OGC API Features

### Migrate the default root

Since 4.0, the default QGIS Server OGC API Features root is `/ogcapi` instead
of `/wfs3`. Set `QGIS_SERVER_API_WFS3_ROOT_PATH` to use another root.

### Export FlatGeobuf

Since 4.2, the QGIS Server OGC API Features service can export FlatGeobuf.
